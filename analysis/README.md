# Analysis Pipeline

The Python pipeline begins at M6, after real session export exists. Planned
modules cover shared signal utilities, audio and vibration features, dataset
construction, baseline model training, evaluation, and matplotlib visualizations.

Python 3.14 is installed on the audited Mac. Before creating `.venv`, M6 will
select a Python version supported by the pinned scientific stack rather than
assuming every dependency already supports 3.14.
