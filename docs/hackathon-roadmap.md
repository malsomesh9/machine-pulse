# Hackathon Roadmap

## Already Built or Validated

- Repository, environment, Compose app shell, debug build, unit tests, and lint:
  validated at M1.
- Hardware capture: not yet validated.
- Real dataset and anomaly separation: not yet validated.

This section is updated only when a milestone's exit evidence exists.

## 30-Hour City Battle Target

1. Harden synchronized sensor capture and the repeatable recording workflow.
2. Validate the baseline model on additional real machines and operating sessions.
3. Port feature extraction, scaling, and anomaly inference onto the Android device.
4. Add evidence-focused result history and comparison visualizations.
5. Measure latency, battery, and thermal behavior on available iQOO hardware.
6. Use Vivo Office Kit only as a development bridge for mirroring, file transfer,
   logs, and model movement where supported.
7. Record a truthful 60-90 second end-to-end demonstration.

Camera/OCR context is a stretch goal after the acoustic-vibration pipeline works.
